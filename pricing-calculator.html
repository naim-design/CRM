How to set up
  1. Open script.google.com → New project.
  2. Paste the sync script (provided with this calculator).
  3. Optional: paste your Drive folder link in FOLDER_LINK.
  4. Deploy → New deployment → Web app → Execute as Me, access Anyone.
  5. Copy the /exec URL here → Connect.

Anyone with the URL can read/write this data — share it only with your team.

Footnotes & Short Forms

1 RRP — Recommended Retail Price (harga runcit cadangan). Dikira: Total cost ÷ RRP cost ratio.
2 COD — Cash on Delivery (caj bayaran semasa penghantaran).
3 ROI — Return on Investment. Dikira: Margin ÷ Total cost.
4 BEP ROAS — Break-Even Point Return on Ad Spend (ROAS minimum untuk pulang modal iklan). Dikira: Promo price ÷ Margin.
5 Margin % — Peratus untung atas harga jual. Dikira: Margin ÷ Promo price.
6 Kos / unit — Kos produk bagi satu unit (belum termasuk pos, packaging, freegift).
7 Package diff — Beza harga promo dengan pakej sebelumnya (kenaikan harga antara pakej). Dikira: Promo price pakej ini − Promo price pakej sebelum.
RM — Ringgit Malaysia · Pkg — Package/Pakej · Freegift — Kos hadiah percuma per pakej.
